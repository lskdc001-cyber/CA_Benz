## 0. 기본 전제

마케팅은 **두 개의 트랙**으로 나뉩니다. 같은 도구가 한쪽에서는 **마케팅 엔진**이고, 다른 쪽에서는 **판매할 상품**이기 때문입니다.

| 트랙 | 대상 | 목적 | 시점 |
|---|---|---|---|
| **A. 고객 확보** | 벤츠 구매 고객 | 본인 판매 실적 증대 | 지금 즉시 |
| **B. 제품 판매** | 동종업계 세일즈 컨설턴트 | 에이전트 SaaS 판매 | 트랙 A 검증 후 |

> **원칙: 트랙 A가 먼저다.**
> 본인 실적으로 증명되지 않은 도구는 동료에게 팔리지 않습니다. 반대로 실적 데이터가 있으면 세일즈가 거의 필요 없습니다. 최소 3개월간 트랙 A를 실전 운영하며 데이터를 축적한 뒤 트랙 B로 넘어갑니다.

## 1. 트랙 A — 벤츠 고객 확보 마케팅

### 1.1 차별화 전략: 자산가 타겟 콘텐츠

대부분의 수입차 세일즈 콘텐츠는 "차량 스펙 + 이달의 프로모션"에 머뭅니다. 여기에 **경제·자산운용 관점**을 결합하면 경쟁자가 거의 없는 자리가 생깁니다.

**콘텐츠 3축**

| 축 | 내용 | 역할 |
|---|---|---|
| ① 차량 | 신차 리뷰, 시승기, 트림 비교, 출고 인증 | 유입·브랜딩 |
| ② 금융 | 리스 vs 할부 vs 현금 비교, 법인차 절세(감가상각·손금산입), 잔가 설정 전략 | 신뢰·전문성 |
| ③ 자산 | 자산 포트폴리오 내 차량 비중, 기회비용 관점의 구매 타이밍, 투자 수익 실현 후 소비 설계 | **차별화·고단가 타겟 유입** |

**③번 축이 핵심 차별화 지점입니다.** 이 콘텐츠에 반응하는 층은 전문직·법인 대표·투자 수익 실현자이며, 이들이 정확히 S클래스·GLE·EQE 등 고단가 모델의 실구매층입니다. 콘텐츠 하나당 기대 계약 단가가 달라집니다.

### 1.2 채널 우선순위

| 순위 | 채널 | 역할 | 발행 주기 |
|---|---|---|---|
| 1 | **네이버 블로그** | "벤츠 GLC 견적", "법인차 리스" 등 구매 직전 검색어 선점. 전환율 최상 | 주 2회 |
| 2 | **인스타그램 릴스** | 신규 노출·브랜딩. 출고 인증샷이 최고 소재 | 주 3회 |
| 3 | **카카오채널** | 기존 상담 이력 고객 재접촉 (사후관리 모듈 직결) | 프로모션 시 |
| 4 | **유튜브 쇼츠** | 릴스 소재 재활용, 추가 제작비 0 | 릴스와 동시 |

**채널별 콘텐츠 매핑**
- 블로그 → ②금융 축 (검색 유입이 가장 강한 주제)
- 릴스/쇼츠 → ①차량 축 (시각적 소재)
- 카카오채널 → ③자산 축 + 프로모션 (이미 신뢰가 형성된 대상)

### 1.3 자동화 루프

```
[콘텐츠 생성 모듈]  주 3회 자동 초안 → 발행
        │
        ▼
      유입 (블로그 검색 / 릴스 노출)
        │
        ▼
[AI 상담봇]  DM·댓글·채널톡 24시간 1차 응대
        │  차종 추천 / 시승 안내 / FAQ
        ▼
  시승·견적·구매 의사 감지
        │
        ▼
[CRM]  리드 자동 등록 + 컨설턴트 인계 알림
        │
        ▼
   대면 상담 → 계약 → 출고
        │
        ▼
[사후관리 자동화]  출고 1주 → 1개월 NPS → 정기점검 → 보험만기 → 24개월 재구매
        │
        └──────────► 소개 · 재구매 (다시 리드로)
```

### 1.4 가장 큰 기회: 소개(Referral) 루프

수입차 판매에서 **기존 고객 소개는 신규 광고 대비 전환율이 압도적으로 높습니다.** 그런데 대부분의 세일즈는 출고 이후 접촉이 끊기면서 이 자산을 그대로 버립니다.

사후관리 자동화가 실제 매출로 연결되는 지점이 정확히 여기입니다:
- 출고 1개월 만족도 체크 → 만족 고객에게 자연스러운 소개 요청 타이밍 확보
- 24개월차 재구매·리스 만기 시점 자동 포착 → 경쟁 딜러보다 먼저 접촉
- 정기점검·보험만기 알림 → "관리해주는 담당자"라는 인식 유지

### 1.5 트랙 A KPI

| 지표 | 측정 방법 | 목표 (3개월) |
|---|---|---|
| 콘텐츠 발행 수 | 콘텐츠 생성 모듈 이력 | 월 20건+ |
| AI봇 유입 리드 | CRM `source = AI봇` | 월 15건+ |
| 리드 → 시승 전환율 | 파이프라인 단계 이동 | 30%+ |
| 시승 → 계약 전환율 | 파이프라인 단계 이동 | 25%+ |
| 사후관리 접촉률 | 팔로업 완료 건수 / 전체 | 90%+ |
| 소개 유입 비중 | CRM `source = 지인소개` | 전체 리드의 20%+ |

## 2. 트랙 B — 에이전트 제품(SaaS) 마케팅

### 2.1 핵심 자산: 업계 네트워크

**금속노조 서울지부 수입자동차지회 한성자동차 대의원 경험**이 이 사업의 가장 큰 유통 자산입니다.

- 한성자동차 내부는 물론 **타 수입차 딜러사 세일즈들과의 직접 접점**
- "동료 편에서 일한 사람"이라는 **신뢰 자본** — 광고비로 살 수 없는 자산
- 세일즈 현장의 실제 페인포인트를 아는 사람이 만든 도구라는 **제품 설득력**

일반적인 SaaS는 이 유통 채널을 만들기 위해 수천만 원의 마케팅비를 씁니다. 이미 갖고 있다는 것이 결정적 우위입니다.

### 2.2 단계별 진행

**1개월차 — 자기 증명**
- 본인 계정으로 실전 운영
- 리드 수 / 응답 속도 / 단계별 전환율 / 소개 비중 데이터 축적
- 이 단계에서는 **아무에게도 팔지 않습니다**

**2~3개월차 — 동료 베타 (5~10명)**
- 무료로 열고 피드백 수집, 온보딩 마찰 지점 파악
- 세일즈 메시지는 기능 설명이 아니라 **숫자 하나**:
  > *"이걸로 월 O대 늘었다"*
- 베타 참여자가 곧 첫 유료 고객이자 레퍼런스가 됨

**4~6개월차 — 유료 전환**
- 개인 월 구독 시작
- 성공 사례 2~3건 확보 → 딜러 지점 단위 B2B 제안

**6개월+ — 확장**
- 타 수입차 브랜드(BMW·아우디·볼보 등) 딜러
- 이후 고관여 내구재(부동산·고급가전·보험) 영업 조직으로 수평 확장

### 2.3 가격 전략

| 플랜 | 대상 | 가격대 | 근거 |
|---|---|---|---|
| 개인 | 세일즈 컨설턴트 1인 | 월 5~10만원 | **차 1대만 더 팔면 회수되는 수준** — 심리적 저항선 아래로 설정 |
| 지점 | 딜러 전시장 단위 | 인당 단가 인하 + 볼륨 | 관리자 대시보드·리드 배분 기능 추가 |

가격 자체보다 **"회수 기간이 얼마나 짧은가"**로 소구합니다. 수입차 세일즈에게 월 10만원은 계약 1건의 인센티브에 한참 못 미치는 금액입니다.

### 2.4 트랙 B KPI

| 지표 | 목표 (6개월) |
|---|---|
| 베타 참여자 | 10명 |
| 유료 전환율 | 베타의 40%+ |
| 유료 구독자 | 15명+ |
| 지점 단위 계약 | 1건+ |
| 월 반복 매출(MRR) | 150만원+ |

## 3. ⚠️ 사전 확인 필수 사항

마케팅 실행 전 반드시 정리해야 할 법적·조직적 이슈입니다. **이 항목들은 나중에 문제가 되면 사업 자체를 중단시킬 수 있습니다.**

### 3.1 사내 규정 및 고객 데이터
- **회사 고객 DB를 개인 도구로 이전하는 것은 개인정보보호법 위반 및 사규 위반 소지가 큽니다.**
- 앱은 **본인이 직접 획득한 리드**(개인 SNS·블로그 유입)부터 시작
- 사내 DB 연동은 반드시 회사 사전 승인 후에만 진행

### 3.2 수신동의 (정보통신망법) — ✅ 앱에 반영 완료
- 카카오 알림톡·문자(SMS) 발송은 **사전 수신동의 필수**, 미동의 발송 시 과태료 부과 대상
- **앱 구현 상태:**
  - CRM 리드 등록 폼에서 수신동의 여부 + 동의 채널을 함께 수집하고, **동의 시점을 기록**
  - 사후관리 메시지를 `거래안내`(출고·정기점검 등, 동의 불필요)와 `광고성`(보험만기·재구매 유도, 동의 필수)으로 구분
  - 동의하지 않은 채널의 광고성 메시지는 `발송 불가` 상태로 자동 차단
  - 동의 철회 시에도 시점을 새로 기록 (증빙 목적)
  - **동의 후 2년이 지나면 자동으로 만료 처리**하고 광고성 발송을 차단 (재동의 전까지 미동의와 동일 취급). 만료 30일 전부터 `만료임박`으로 표시
- **실발송 연동 시 추가 필요:** 광고성 메시지 본문 `(광고)` 표기, 수신거부 방법 명시

### 3.3 브랜드 가이드라인
- 벤츠코리아 / 한성자동차 **공식 로고·이미지 무단 사용 금지**
- 개인 세일즈 홍보 허용 범위 사전 확인
- 공식 채널로 오인될 수 있는 계정명·프로필 구성 회피

### 3.4 이해충돌
- 동료 세일즈에게 유료 제품을 판매하는 것은 회사와의 관계 정리가 필요한 사안
- 겸업 규정, 사내 영업 행위 제한 여부 확인
- **대의원 경험을 살려 사전에 명확히 정리해두는 것이 안전합니다** — 사후 문제 제기보다 사전 협의가 압도적으로 유리

## 4. 실행 로드맵 요약

| 기간 | 트랙 A (고객 확보) | 트랙 B (제품 판매) |
|---|---|---|
| **1개월** | 콘텐츠 3축 세팅, 채널 개설, 주 3회 발행 시작 | (없음) — 데이터 축적만 |
| **2~3개월** | 자동화 루프 안정화, 소개 루프 가동 | 동료 베타 5~10명 모집 |
| **4~6개월** | 전환율 최적화, 고단가 모델 집중 | 유료 전환, 지점 B2B 제안 |
| **6개월+** | 유지·확대 | 타 브랜드 딜러 확장 |

**선행 조건 (전 단계 공통):** 3장의 사전 확인 사항 정리 완료
