# 세일즈 비서 에이전트(Sales Secretary Agent) 사업 기획서

**작성자:** 한성자동차 벤츠 세일즈 컨설턴트
**작성일:** 2026-09-07
**버전:** v1.0 (초안)

---

## 1. 사업 개요

### 1.1 배경
수입차(벤츠) 딜러 세일즈는 상담 → 견적 → 계약 → 출고 → 사후관리(정기점검, 보험, 재구매, 소개)로 이어지는 긴 고객 여정을 한 명의 세일즈 컨설턴트가 전부 감당한다. 신규 리드 응대, SNS 콘텐츠 제작, 고객 DB 관리, 출고 후 사후관리 알림까지 수작업으로 처리하면 정작 중요한 "대면 상담·클로징"에 쓸 시간이 부족해진다.

**"세일즈 비서 에이전트(Sales Secretary Agent)"** 는 세일즈 컨설턴트 개인 또는 딜러 지점을 위한 AI 자동화 도구로, 다음 4가지 영역을 자동화하여 세일즈가 본연의 업무(상담·클로징·관계관리)에 집중할 수 있게 한다.

### 1.2 미션
> "AI가 비서 역할을 대신하여, 세일즈 컨설턴트는 사람 대 사람의 신뢰 구축에만 집중한다."

### 1.3 타겟 고객
- **1차 타겟:** 한성자동차 등 수입차 딜러 소속 개인 세일즈 컨설턴트
- **2차 타겟:** 딜러 지점(전시장) 단위 도입 — 여러 세일즈가 함께 리드를 공유·배분
- **확장 타겟:** 타 브랜드(수입/국산) 자동차 딜러, 나아가 고관여 내구재(가전, 부동산 등) 영업 조직

## 2. 4대 자동화 영역

### ① 기획 (Planning / CRM 기반 영업 전략)
- 리드/고객 데이터를 기반으로 한 영업 파이프라인 시각화 (신규 문의 → 상담 → 시승 → 견적 → 계약 → 출고)
- 월별/차종별 목표 대비 실적 대시보드
- 고객 세그먼트별(신규/재구매/소개) 접근 전략 제안

### ② 광고 (Marketing / 콘텐츠 자동 생성)
- 차종·프로모션 정보를 입력하면 SNS(인스타그램, 블로그, 카카오채널) 홍보 문구, 카드뉴스 스크립트, 상담 유도 문구를 AI가 자동 생성
- 톤앤매너(신뢰감 있는 전문 컨설턴트 톤) 템플릿 적용
- 시즌 프로모션·신차 출시 일정에 맞춘 콘텐츠 캘린더 자동 제안

### ③ AI 상담 (AI 고객 상담봇)
- 홈페이지/카카오톡 채널에 임베드 가능한 24시간 AI 상담 챗봇
- 차종 추천, 견적 문의, 시승 예약, 자주 묻는 질문(할부·리스·트레이드인) 자동 응대
- 상담 난이도가 높거나 클로징 임박 건은 실제 세일즈 컨설턴트에게 핸드오프(알림)
- 모든 상담 이력은 CRM에 자동 연동되어 리드로 등록

### ④ 사후관리 (After-Sales Automation)
- 출고 후 자동 팔로업 시퀀스: 출고 1주/1개월/6개월/정기점검 시점/보험 만기 시점에 자동 알림 발송
- 소개·재구매 유도 메시지 자동 타이밍 제안 (예: 출고 24개월차 리스 만기 임박 고객)
- 고객 만족도 체크(NPS) 자동 설문 발송 및 결과 집계

### 3.1 기술 스택 (제안)
| 영역 | 기술 |
|---|---|
| 프론트엔드 | Next.js (React) + TypeScript |
| 백엔드 | Next.js API Routes (서버리스 호환) |
| 데이터 저장 | 초기: JSON 파일 기반 DB(경량) → 확장: PostgreSQL/Supabase |
| AI 엔진 | Anthropic Claude API (상담봇 응답, 콘텐츠 생성) |
| 알림 발송 | 카카오 알림톡 API / 이메일(SMTP) / 문자(SMS) 연동 (2차 확장) |
| 배포 | Vercel 또는 사내 서버 |

## 4. 개발 로드맵

### Phase 0 — 기획 (완료 목표: 본 문서)
- 사업 모델 및 4대 기능 정의 ✅

### Phase 1 — 프로토타입 (클릭 가능한 데모)
- 대시보드 UI, 4대 기능 화면 흐름을 정적 목업으로 시연
- 실제 데이터 연동 없이 핵심 사용자 경험(UX) 검증

### Phase 2 — MVP(실제 앱) 개발
- CRM(리드/고객 관리): 등록·조회·상태 변경(파이프라인)
- AI 상담봇: Claude API 연동, 기본 시나리오(차종 추천/견적/시승예약) 응답
- 콘텐츠 자동 생성: 프롬프트 템플릿 기반 SNS 문구 생성기
- 사후관리 자동화: 출고일 기준 팔로업 일정 자동 계산 + 할일 목록화

### Phase 3 — 고도화
- 카카오 알림톡/문자 연동으로 실제 자동 발송
- 다중 세일즈 컨설턴트/지점 계정 지원 (권한 분리)
- 상담봇 실제 임베드(위젯) + 실시간 핸드오프
- 통계/리포트 고도화 (전환율, 응답 속도, 고객 만족도)

### Phase 4 — 확장
- 타 세일즈 컨설턴트/지점 대상 SaaS화
- 타 브랜드/업종 화이트라벨 버전

## 5. 성공 지표 (KPI)
- 리드 응대 소요 시간 단축률
- AI 상담봇을 통한 신규 리드 확보 건수
- 콘텐츠 제작 소요 시간 단축률
- 사후관리 접촉을 통한 재구매/소개 전환율
- 고객 만족도(NPS) 점수

---

## 6. 리스크 및 고려사항
- **개인정보보호:** 고객 연락처/차량정보 등 민감정보 취급 → 접근 권한 관리, 데이터 암호화 필요
- **AI 응답 신뢰성:** 가격/할부 조건 등 민감한 정보는 AI가 확정 답변하지 않고 "정확한 견적은 컨설턴트 상담으로 연결" 형태로 설계
- **브랜드 가이드라인 준수:** 벤츠코리아/한성자동차의 공식 커뮤니케이션 가이드라인 내에서 콘텐츠 생성
- **노조/개인정보 규정:** 대의원 경험을 살려 고객정보 활용에 대한 내부 규정·직원 개인정보 처리방침 준수 확인
